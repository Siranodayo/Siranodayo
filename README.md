### ✦ about

やっほー、白乃（しらの）です。

モデルやキャラクターのビジュアルを考えるのが好きです。  
websiteの配置やキャラクター……「どうやって作成しよう」って想像してる時間が、いちばん好きかもしれません。

日ごろは、わりとゲームばかりやってます。
コードも触れます。`HTML` / `CSS` / `JavaScript` / `Java` / `Python` は使えます。  
得意ってほどじゃなくても、静かに画面とにらめっこして、なんとか形にできるタイプです。
<br />

<details>
<summary><b>もう少しだけ</b></summary>
<br />

「白」は、誰もいない朝の白に近いです。  
「乃」は、やわらかくて、少し古くて、呼び捨てにすると寂しさが残る感じ。

人と話すのは好きだけど、にぎやかさより、夜にぽつぽつ話す距離感がちょうどいいです。  
完璧より余韻。説明より残り香。そういうのを、見た目にも込めたいです。

</details>
